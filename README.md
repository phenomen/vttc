# VTTC  - VTT Media  Converter & Optimizer

A CLI media converter and optimizer powered by [Bun.Image](https://bun.com/docs/runtime/image) and [Mediabunny](https://github.com/Vanilagy/mediabunny).

## Features

- Convert images to WEBP, PNG, JPEG
- Convert videos to WEBM, MP4
- Convert audio to OGG, AAC
- Batch processing with quality options
- Preserves directory structure

## Requirements

- Bun v1.3.14 or newer

## Usage

```bash
bunx vttc
```

## Supported Input Formats

**Images:** AVIF, GIF, JPEG, JPG, PNG, TIFF, WEBP, JFIF

**Videos:** AVI, M4V, MKV, MOV, MP4, MPEG, WEBM, WMV

**Audio:** All video formats plus AAC, FLAC, M4A, MP3, OGG, WAV
